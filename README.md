# Play One?!

一個用來發起手遊邀約、蒐集朋友可玩時間的網頁原型。

## 目前可操作功能

- 大廳依日期列出最近邀約
- 發起邀約，可選擇或自行輸入遊戲名稱
- 多選預設時段，亦可自行新增時段
- 分享邀約連結
- 朋友填暱稱與可玩的時間
- 即時彙整各時段可參加的人數

此版以瀏覽器 `localStorage` 儲存示範資料，適合先確認畫面和操作流程。下一階段可將邀約與回覆資料接到 Supabase。

## 本機預覽

以靜態檔案伺服器開啟此資料夾，例如：

```powershell
python -m http.server 4173
```

再造訪 `http://localhost:4173`。
